# 多语言贡献指南

[English](./i18n.en.md)

SQL 之母保留简体中文为默认语言，提供完整的英文界面和目前 45 个已启用关卡的英文教程。使用页头的语言选择器切换语言；选择保存在浏览器本地，不影响当前 SQL、查询结果和练习广场的数据库。

## 文件组织

- `src/i18n/messages/zh-CN.ts`：原始界面文案和文案键类型。
- `src/i18n/messages/en.ts`：英文界面文案。
- `src/i18n/index.ts`：语言列表、选择状态、存储和 `t()`。
- `src/i18n/lessons.ts`：通过 Vite 加载关卡译文，仅返回标题、正文和提示。
- `src/levels/main/level1/locales/en.md`：关卡正文译文。
- `src/levels/main/level1/locales/en.json`：该关卡的标题和提示。

原有 `README.md`、`index.ts`、`createTable.sql` 是中文教程和可执行关卡的来源。界面显示译文，SQL 编辑器仍使用原始关卡对象，因此切换语言不会重新初始化数据库。

## 新增语言

以法语 `fr` 为例：

1. 复制 `src/i18n/messages/en.ts` 为 `fr.ts` 并翻译值，保留文案键以及 `{error}` 等插值名称。保留 `Record<keyof typeof zhCN, string>` 类型，编译器会检查缺失文案。只需更改导出的变量名，无须增加依赖。
2. 在 `src/i18n/index.ts` 导入新文案，把 `fr` 加入 `messages`，并在 `locales` 中加入 `{ code: "fr", label: "Français" }`。语言名称使用本语言，便于读者识别。
3. 在 `src/App.vue` 导入 Ant Design Vue 已有的 `ant-design-vue/es/locale/fr_FR`，并添加到 `antdLocales`。页面标题、描述、关键词和 HTML `lang` 会随语言更新。
4. 在要翻译的关卡 `locales` 目录添加 `fr.md` 和 `fr.json`，Vite 会自动发现这些文件，无须改动关卡注册列表。主线和自定义关卡均适用。

元数据格式：

```json
{
  "title": "关卡的译文标题",
  "hint": "关卡的译文提示"
}
```

关卡原本没有提示时可省略 `hint`。译文缺失或为空时，对应的标题、正文、提示会分别回退到原始中文。新增语言可以逐步贡献，但请在 PR 中明确覆盖范围。当前译文采用静态导入，与原项目课程加载方式一致。

## 翻译规则

- 翻译完整教程、示例说明、题目要求和提示，保留 Markdown 表格和代码块。
- 不翻译 SQL 表名、列名、别名或字符串值。比如题目要求 `gender = '男'`，应解释 `男` 表示 male，不能把查询改成 `gender = 'male'`；中文结果列别名也必须保持原样。
- 示例表格中的姓名、分类等数据与查询相互对应，保留原值。SQL 注释可以翻译。
- 不为翻译更改 `initSQL`、`defaultSQL`、`answer`、关卡 key 或判题逻辑。编辑器中的原始 SQL 和数据库内容可能含有中文，这些是练习数据的一部分。
- 题目应明确要求的输出列名、顺序、筛选条件、排序和数量。发现原教程与答案不一致时，在 PR 中说明；不要静默改变答案。
- 保留鱼皮的署名、原项目链接和现有作者资源。无需实时翻译服务、API 密钥或后端。

## 验证

```bash
npm ci
npm test
npm run build
```

测试使用 Node.js 内置测试运行器（Node 18+）和项目已有的 Vite、sql.js，无新增依赖；验证界面键及插值、语言偏好、受限存储、45 个关卡英文覆盖、中文回退、源关卡不变和全部参考答案执行。

还请在浏览器中检查：切换语言后保留已输入 SQL、结果、当前关卡和展开的提示；刷新保留语言；练习广场中创建或修改的数据仍可查询；关卡列表、作者介绍、错误提示和窄屏布局正常。

原项目的 `vue-tsc --noEmit` 存在练习广场未传入必填 `resultStatus` 的类型诊断；翻译贡献不改变这些原有组件接口。生产构建也有原有 CSS 嵌套和大体积 chunk 警告。
